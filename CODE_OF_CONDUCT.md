# Code of Conduct

We want product managers, developers, researchers and first-time contributors to participate without harassment.

Be respectful and specific. Critique evidence, methods and changes rather than people. Welcome different experiences and skill levels. Protect private information.

Harassment, threats, discriminatory abuse, sexualized attention, deliberate intimidation, impersonation and publishing another person's private information are unacceptable.

The maintainer may edit/remove harmful content, limit participation or block a participant when necessary. Decisions should consider context and proportionality. Report concerns through an available private channel on the [maintainer's GitHub profile](https://github.com/JaneHuang1833); do not publish private allegations or evidence in an issue.

This policy applies to the repository's issues, pull requests and related project spaces. Participation does not create a response-time guarantee.
