# Privacy

Skill Product Manager does not run a hosted service, collect telemetry, store credentials or send data to a maintainer-controlled endpoint.

When the host applies a skill, its model provider, enabled search tools and connected services may process the input and tool calls under their own terms. Installing these instruction files does not make model processing local.

Discovery files are saved in the workspace only when file tools are available. The host and the user control retention, backups and sharing. The plugin does not automatically upload them.

For public research, abstract confidential ideas instead of submitting private text verbatim. Keep credentials, private URLs and identifying research material out of issues, examples and releases. Export only material the user is authorized to share.

This notice describes this repository's code and instructions; it does not replace the host's or connector's privacy policies.
