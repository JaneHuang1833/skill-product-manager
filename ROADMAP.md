# Roadmap

This is a direction of travel, not a promised release schedule.

## Current: 0.2.0

Seven discovery skills, shared evidence contracts, bounded decision routes, English metadata/docs, synthetic examples, deterministic scoring, package validation and release archives.

## Next candidates

- Publish reproducible client installation checks with exact versions.
- Build a small dated benchmark for canonical candidate relevance and evidence handling.
- Evaluate routing and resume behavior with realistic independent cases.
- Improve artifact validation only where real integration needs justify executable schemas.
- Gather actual user feedback on question burden and decision usefulness.

## Intentionally outside current scope

A hosted discovery service, exhaustive ecosystem index, autonomous outreach, background agents, automatic experiment launches and generated-product deployment.

New work should have a concrete job, evidence and a maintenance budget. A useful STOP or reuse recommendation remains a successful outcome.
