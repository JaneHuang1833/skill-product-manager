# Support

Start with [installation](docs/installation.md), [usage](docs/usage.md) and the [examples](examples/README.md).

For a reproducible defect, open a [bug report](https://github.com/JaneHuang1833/skill-product-manager/issues/new?template=bug_report.yml). Include release, host/version, platform, minimal prompt, available tools and expected versus actual behavior.

For a workflow improvement, use a [feature request](https://github.com/JaneHuang1833/skill-product-manager/issues/new?template=feature_request.yml). Explain the user's job and evidence rather than only listing features.

Report vulnerabilities through [SECURITY.md](SECURITY.md). Do not upload private notes, credentials or customer data.

This is a community-maintained project. There is no service-level agreement, guaranteed turnaround or professional product advisory service.
