# Skill Product Manager 0.2.0

The first public release of seven product discovery skills, fully documented in English.

- Frame a job, inspect existing solutions, compare alternatives and choose a decision route.
- Preserve source provenance, uncertainty, limited/offline research and user overrides.
- Design a cheapest test or define a bounded 18-section product spec and handoff.
- Install through the repository marketplace or a self-contained release ZIP.
- Includes MIT licensing, synthetic examples, community guides, regression tests and checksums.

The plugin is skills-only: no bundled server, credentials, telemetry or background agent. Host tools determine live research capability. Structural validation does not establish universal client compatibility or decision accuracy.

See the installation guide and changelog in the repository. GitHub publication does not submit this plugin to OpenAI's universal public Plugins Directory.
